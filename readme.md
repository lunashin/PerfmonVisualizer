# 仕様
## 言語
Excel VBAプログラム (ボタンクリック後のイベントハンドラ内から呼び出す関数1つ. 内部処理は関数化してもOK)

## CSV仕様
- perfmonが出力したコンマ区切りのcsvファイルを扱う。
- 上記csvファイルは、先頭カラムは日時、2番目以降のカラムは測定パラメータの実測値が記載されている。
- 最初にcsvを選択するためのファイルダイアログを表示する
- 選択されたcsvファイルを読み込み、data_[ログ開始日時]-[ログ終了日時] シートを作成して、その中へ展開する
## シート仕様
- data_[ログ開始日時]-[ログ終了日時] シートが既にある場合は削除して作成する。
- graph_[ログ開始日時]-[ログ終了日時] シートを作成し、プログラム内で指定されたカラムを折れ線グラフとして作成する。
- graph_[ログ開始日時]-[ログ終了日時] シートが既にある場合は削除して作成する。
- シート名の日時は分までとする
## グラフ仕様
- グラフ化の対象とするperfmon監視項目を以下1から読み取る。
- 複数のperfmon監視項目を同一のグラフにまとめる(以下2で定義)
- グラフの縦横幅を以下3から読み取る。
- グラフ化する日時範囲を以下4から読み取る
- 複数のグラフを作成する場合は、縦に並べる。
- グラフの下限値は0, 上限値は最大値の+20%とする。
- グラフ線の色を以下1の文字色を読み取り設定
- 以下3を読み込み、監視項目の短い説明をグラフのタイトルとして利用。グラフタイトルのフォーマットは、"perfmon監視項目(perfmon監視項目の短い説明)" とする。
- グラフ横軸の時刻を少なくとも1時間単位で表示
- perfmon監視項目毎に日次グラフ作成機能。(各日のパフォーマンス比較)
- 日次グラフは、各グラフの横軸を24時間とし、perfmon監視項目毎に、日毎のグラフを同一グラフに表示。開始日時と終了日時は適用し、時刻指定は無視する。B列の文字色は無視し、対象日を古い順に自動配色。同じ日付は全グラフで同じ色とする。
## グラフ更新機能
- 最後に読み取ったデータを対象にグラフを更新する
- 改めてデータを読み込むことなく、最後に読み込んだデータのグラフに対して [管理コンソール]シート の設定を反映する機能
- 最後に作成したグラフシート内のグラフを全て削除し、[管理コンソール]シート の設定を反映してグラフを作成する

## [管理コンソール]シート仕様
- グラフ描画時の動作については[管理コンソール]シートにパラメータを設定可能とする(以下、[管理コンソール]シート仕様 の項を参照)
1. B22:B72 = グラフ化の対象とするperfmon監視項目
2. C22:C72 = グラフ番号(同一のグラフにまとめる際に指定. 未記載は単一のグラフとする)
3. D22:D72 = perfmon監視項目の説明を記載。グラフのタイトルとして設定する。
4. H22 = 横幅(単位はpx, 空欄の場合は画面幅に合わせる(画面リサイズに対応)), H23 = 縦幅(px)
5. H24 = 開始日時(時刻がない場合は0:00とする, 空欄の場合は範囲指定なし), H25 = 終了日時(時刻がない場合は23:59とする, 空欄の場合は終了日時指定なし)
6. H26: 1の場合、日次グラフを作成。
